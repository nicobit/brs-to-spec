# Skill - Create or Normalize BRS

## Identity

```text
skill_id:    product-owner.create-brs
persona:     product-owner
action_id:   create-brs
produces:    input/brs.md
```

## When this skill is used

Run this only when asked to create a new BRS or normalize unstructured business input into BRS form.

## Preconditions

Before starting, verify there is enough business source material to create meaningful objectives, requirements, constraints, and open questions.

## Instructions

Write or normalize the BRS into structured business language with explicit functional and non-functional requirements, constraints, and unresolved questions.

## Output requirements

Use `.b2s/artifact-templates/brs.md` as the shape contract.
