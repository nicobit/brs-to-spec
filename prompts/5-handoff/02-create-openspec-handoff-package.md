# Prompt — Create OpenSpec Handoff Package

## Purpose

Prepare a compact handoff package before finalizing the OpenSpec change.

## Output file

```text
handoff/openspec-handoff-package.md
```

## Include

- active deliverable,
- business value,
- included requirements,
- excluded scope,
- modules touched,
- architecture constraints,
- architecture decisions,
- acceptance criteria,
- automated validation expectations,
- open risks,
- required advanced contracts.
