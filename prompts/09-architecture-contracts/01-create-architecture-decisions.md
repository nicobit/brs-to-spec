# Prompt — Create Architecture Decisions / ADRs

Output:
Create or update:

```text
features/<feature-name>/architecture-contracts/architecture-decisions.md
```

Optionally create ADR files under:

```text
features/<feature-name>/architecture-contracts/adr/
```

Use ADRs for meaningful architecture decisions, especially missing decisions from `brs-architecture-alignment.md`.

ADR structure:

```markdown
# ADR-001 — <Decision Title>

## Status
Proposed / Accepted / Superseded / Rejected

## Context

## Decision

## Consequences

## Alternatives Considered

## Related Requirements

## Related Architecture Alignment Findings

## Related OpenSpec Tasks
```
