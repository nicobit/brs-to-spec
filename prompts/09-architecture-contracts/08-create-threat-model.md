# Prompt — Create Threat Model

Use when the change is security-sensitive: new API, sensitive data, authorization changes, external integration, file upload, audit/compliance requirement, or infrastructure risk.

Output:
Create:

```text
features/<feature-name>/architecture-contracts/threat-model.md
```

Include:
- assets,
- trust boundaries,
- entry points,
- data flows,
- threats,
- mitigations,
- residual risks,
- security validation tasks.
