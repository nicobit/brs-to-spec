# Prompt — Create Data Model / Database Change Contract

Use when tables, columns, indexes, constraints, views, migrations, retention, or data security are affected.

Output:
Create:

```text
features/<feature-name>/architecture-contracts/data-model.md
```

Include:
- existing data structures,
- new/changed tables,
- columns,
- keys and constraints,
- indexes,
- migration strategy,
- backward compatibility,
- data retention,
- audit fields,
- validation queries.
