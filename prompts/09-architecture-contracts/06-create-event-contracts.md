# Prompt — Create Event / Message Contracts

Use when the feature creates, consumes, or changes events, messages, queues, topics, audit events, integration events, or outbox records.

Output:
Create:

```text
features/<feature-name>/architecture-contracts/event-contracts.md
```

Include:
- events produced,
- events consumed,
- schema,
- producer/consumer,
- trigger,
- versioning,
- delivery guarantees,
- idempotency,
- retry/dead-letter handling,
- audit considerations.
