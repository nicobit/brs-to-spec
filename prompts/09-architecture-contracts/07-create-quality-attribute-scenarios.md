# Prompt — Create Quality Attribute Scenarios

Use when NFRs are important, vague, risky, or need measurable validation.

Output:
Create:

```text
features/<feature-name>/architecture-contracts/quality-attribute-scenarios.md
```

Convert vague NFRs into measurable scenarios covering:
- performance,
- availability,
- reliability,
- security,
- maintainability,
- observability,
- scalability.

Each scenario should include stimulus, environment, response, measure, and validation approach.
