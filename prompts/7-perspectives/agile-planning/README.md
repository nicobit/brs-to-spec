# Agile Planning Perspective

This perspective maps framework outputs into Agile / GitLab planning language.

It is useful when teams plan with Epics, Features, User Stories, Issues, Tasks, Milestones and Labels.

## Important

This is a planning projection, not a new source of truth.

Do not edit the generated planning view to change requirements, scope, architecture, quality gates or implementation tasks.

Update the source artifacts and regenerate the view.
