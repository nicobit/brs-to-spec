# UC-001: Submit Application

## Metadata

| Field | Value |
|---|---|
| UC ID | UC-001 |
| Title | Submit Application |

## Description

Applicant submits a loan application via the public intake form.

## Preconditions

- Applicant has required identity data and supporting documents.

## Main Success Scenario

1. Applicant fills intake form and submits.
2. System validates inputs and returns inline errors if any.
3. On success, system creates `Application` and assigns `application_id` (ARN).

## Postconditions

- Application created in Draft/Submitted state.

- FR-001, FR-002, FR-003
