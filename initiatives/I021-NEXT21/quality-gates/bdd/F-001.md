## SCN-001 - Auto-approve eligible application (Happy path)

| Field | Value |
|---|---|
| ID | SCN-001 |
| Story | F-001.1 |
| Requirement | FR-010 |
| AC | AC-001 |
| Type | Happy path |
| Priority | Must |

```gherkin
Scenario: Auto-approve eligible application when score and amount criteria met
  Given an applicant submits a complete application with ARN A-100
  And Experian credit lookup returns a score of 820
  And AML and KYC checks pass
  And the requested amount is £5,000
  When the scoring engine produces recommendation AUTO_APPROVE
  Then the system creates an offer and marks the application as OFFERED
  And the applicant receives an offer email containing ARN A-100
  And an audit event "OFFER_CREATED_AUTO_APPROVE" is recorded with ARN A-100
```

```gherkin
Scenario: Route to underwriter when Experian API is unavailable
  Given an applicant submits a complete application with ARN A-200
```
