## SCN-011 - AML screening blocks application (Happy path)

| Field | Value |
|---|---|
| ID | SCN-011 |
| Story | F-003.1 |
| Requirement | FR-012 |
| AC | AC-011 |
| Type | Happy path |
| Priority | Must |

```gherkin
Scenario: AML screening flags and blocks an application
  Given an applicant submits an application with ARN A-700
  And AML screening returns a match on sanctions list
  When the system processes the AML result
  Then the application enters COMPLIANCE_HOLD
  And a notification is sent to the compliance team
  And an audit event "APPLICATION_FLAGGED_AML" is recorded
```
