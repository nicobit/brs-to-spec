## SCN-007 - AI scoring produces recommendation (Happy path)

| Field | Value |
|---|---|
| ID | SCN-007 |
| Story | F-002.1 |
| Requirement | FR-006 |
| AC | AC-007 |
| Type | Happy path |
| Priority | Must |

```gherkin
Scenario: Scoring engine returns a recommendation within SLA
  Given an applicant submits a complete application with ARN A-600
  And Experian and required inputs are available
  When the scoring engine runs
  Then the scoring pipeline returns a numeric score and a recommendation within 90 seconds
  And the recommendation is one of AUTO_APPROVE, REFER_TO_UNDERWRITER, or AUTO_DECLINE
  And an audit event "SCORING_COMPLETED" is recorded with ARN A-600
```

## SCN-008 - Scoring input validation fails (Validation)

| Field | Value |
|---|---|
| ID | SCN-008 |
| Story | F-002.2 |
| Requirement | FR-008 |
| AC | AC-008 |
| Type | Validation |
| Priority | Must |

```gherkin
Scenario: Scoring rejects request when required model inputs are missing
  Given an applicant submission missing income and employment stability fields
  When the scoring pipeline attempts to evaluate the model
  Then the scoring pipeline returns an input-validation error and the application is routed to REFERRAL
  And no recommendation is produced
  And an audit event "SCORING_INPUT_VALIDATION_FAILED" is recorded
```

| AC | AC-009 |
| Type | Integration failure |
| Priority | Must |

```gherkin
Scenario: Experian API failure causes routing to underwriter
  Given an applicant submits an application with ARN A-610
  And the Experian API is unavailable
  When the scoring workflow requires bureau data
  Then the application is routed to REFER_TO_UNDERWRITER
  And a queue item is created for the underwriter team
  And an audit event "EXPERIAN_UNAVAILABLE_ROUTE_TO_UNDERWRITER" is recorded
```
