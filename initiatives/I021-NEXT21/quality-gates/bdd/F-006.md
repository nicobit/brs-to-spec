| Field | Value |
|---|---|
| ID | SCN-021 |
| Story | F-006.1 |
| Requirement | FR-024 |
| AC | AC-021 |
| Type | Happy path |
| Priority | Must |

```gherkin
Scenario: Disbursement instruction is sent to T24 and confirmed
  Given an application ARN A-1000 has completed cooling-off
  When the system sends a disbursement instruction to T24
  Then T24 returns a confirmation and the application status becomes DISBURSED
  And an immutable audit event "DISBURSEMENT_CONFIRMED" is recorded
```

| Requirement | FR-026 |
| AC | AC-022 |

```gherkin
Scenario: Disbursement fails then retries and alerts ops
  Given a disbursement instruction fails due to network error
  When the system retries one time and still fails
  Then an alert is sent to operations with the disbursement ARN
  And an audit event "DISBURSEMENT_RETRY_FAILED" is recorded
```
