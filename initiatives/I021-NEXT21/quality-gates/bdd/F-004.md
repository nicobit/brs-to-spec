## SCN-014 - Underwriter approves referred application (Happy path)

| Field | Value |
|---|---|
| ID | SCN-014 |
| Story | F-004.1 |
| Requirement | FR-015 |
| AC | AC-014 |
| Type | Happy path |
| Priority | Must |

```gherkin
Scenario: Underwriter approves a referred application
  Given an application ARN A-800 is in the underwriter queue with recommendation REFER_TO_UNDERWRITER
  And an underwriter U-200 is authenticated with role Underwriter
  When the underwriter approves the application with condition "Income verified"
  Then the application status becomes APPROVED_WITH_CONDITION
  And the approval record contains underwriter ID U-200 and timestamp
  And an audit event "UNDERWRITER_APPROVED" is recorded
```
