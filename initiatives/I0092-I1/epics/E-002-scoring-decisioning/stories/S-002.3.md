# S-002.3 — Real-time decision rules and auto-approve (FR-010, FR-011)

| Layers | backend |

## Business Context

Automated decision rules speed up approvals and reduce manual workload.

## User Story

As a decision engine, I want to apply business rules to scores so that clear auto-approve/decline actions can be taken.

## Implementation Guidance

Implement rule engine with configurable thresholds and audit hooks.

## Test Expectations

- Unit tests for rules and integration with score input

## Requirements

- FR-010, FR-011, REQ-005, REQ-006

## Acceptance Criteria (Gherkin)

```gherkin
Scenario: Auto-approve when threshold met
  Given a scored application with score above threshold
  When rules are evaluated
  Then application status is set to APPROVED

Scenario: Auto-decline when below threshold
  Given a scored application below decline threshold
  When rules are evaluated
  Then application status is set to DECLINED
```
