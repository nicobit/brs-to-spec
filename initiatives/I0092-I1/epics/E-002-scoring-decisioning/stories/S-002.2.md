# S-002.2 — Experian integration and input enrichment (FR-008, FR-009)

| Layers | integration, backend |

## Business Context

Credit bureau enrichment provides additional data points used by scoring models.

## User Story

As a scoring service, I want to enrich application records with Experian data so that scores have full contextual inputs.

## Implementation Guidance

Use an adapter with retry and circuit-breaker; cache responses for a short TTL to reduce calls.

## Test Expectations

- Integration tests with mocked Experian responses

## Requirements

- FR-008, FR-009

## Acceptance Criteria (Gherkin)

```gherkin
Scenario: Enrichment success
  Given a valid application
  When the enrichment adapter calls Experian
  Then enrichment fields are stored on the application record

Scenario: Experian failure handled
  Given Experian returns an error
  When the adapter is called
  Then the system records the failure and continues with partial data
```
