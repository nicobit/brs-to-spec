# S-002.5 — Scoring dashboard UI (frontend)

| Layers | frontend |

## Business Context

Provide a simple UI for operators to view scores and reasons during early testing.

## User Story

As an operator, I want to view application scores and explainability so that I can spot-check decisions.

## Implementation Guidance

Build a minimal frontend view that calls GET /score/{applicationId} and displays score and modelVersion.

## Test Expectations

- Manual UI check and smoke tests

## Requirements

- REQ-005

## Acceptance Criteria (Gherkin)

```gherkin
Scenario: Dashboard shows score
  Given an application with a score
  When the operator opens the dashboard
  Then the score and modelVersion are displayed

Scenario: Dashboard handles missing score
  Given an application without a score
  When the operator opens the dashboard
  Then a friendly message indicates missing score
```
