
# S-005.1 — Offer template engine

| Layers | backend, integration |

## Business Context

Automating offer generation reduces time to offer and makes acceptance auditable.

## User Story

As a system, I want to generate and send offers via DocuSign so that applicants can accept electronically.

## Implementation Guidance

Implement a templating engine and DocuSign adapter; provide hooks for offer validation.

## Test Expectations

- Integration tests with DocuSign sandbox

## Requirements

- FR-020, FR-021, FR-022, FR-023, FR-024

## Acceptance Criteria (Gherkin)

```gherkin
Scenario: Offer sent to applicant
	Given an approved application
	When the offer engine generates the offer
	Then an envelope is created in DocuSign and a link is sent to the applicant

Scenario: Acceptance recorded
	Given the applicant signs the document
	When DocuSign notifies the system
	Then the acceptance is recorded with timestamp and IP
```
