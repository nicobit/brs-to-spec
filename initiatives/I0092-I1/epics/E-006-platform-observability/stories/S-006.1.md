
# S-006.1 — Metrics for ingestion pipeline

| Layers | backend, infrastructure |

## Business Context

Visibility into pipeline performance enables quicker response to issues and scaling decisions.

## User Story

As an operator, I want metrics for ingestion so that I can monitor throughput and errors.

## Implementation Guidance

Instrument key pipeline stages and expose metrics via Prometheus-compatible endpoints.

## Test Expectations

- Integration test for metrics exposure and sample dashboard

## Requirements

- FR-029, FR-030, NFR-001

## Acceptance Criteria (Gherkin)

```gherkin
Scenario: Metrics available
	Given the ingestion pipeline is running
	When metrics endpoint is queried
	Then metrics for throughput and error rates are returned

Scenario: Alerts on threshold
	Given error rate exceeds threshold
	When metrics are evaluated
	Then an alert is triggered
```
