# S-003.1 — Watchlist integration

| Layers | backend, integration |

## Business Context

Automated watchlist checks reduce regulatory risk and surface candidates for manual review.

## User Story

As a compliance analyst, I want the system to run watchlist checks so that suspect applications are flagged.

## Implementation Guidance

Use the compliance adapter and record evidence in the compliance log; reference `implementation-contract.md`.

## Test Expectations

- Integration tests with sample watchlist hits and misses


## Description

Implement watchlist checks and record evidence for flagged applications.

## Requirements

- FR-012, FR-013, FR-014

## Acceptance Criteria (Gherkin)

```gherkin
Scenario: Watchlist hit
	Given an application matches a watchlist entry
	When the compliance service runs
	Then the application is flagged and evidence is stored

Scenario: No match
	Given no watchlist match
	When the compliance service runs
	Then no flag is raised and processing continues
```
