## Acceptance Criteria

### AC-001 — Experian call succeeds `[integration]`

```gherkin
Scenario: Retrieve credit report
  Given an application requires credit data
  When the Experian adapter requests a credit report
  Then a credit report is returned within 30 seconds or the adapter falls back to REFER_TO_UNDERWRITER
```

### AC-002 — Experian timeout and fallback `[integration]`

```gherkin
Scenario: Experian times out and adapter falls back
  Given Experian does not respond within 30 seconds
  When the adapter retries per retry-policy and still fails
  Then the adapter emits an internal `experian.failure` event and the scoring flow chooses REFER_TO_UNDERWRITER
```

## Business Context

Experian integration supplies deterministic credit inputs necessary for accurate scoring. This adapter reduces false negatives by providing retries and clear fallback semantics.

## Implementation Guidance

Reference `implementation-contract.md` for event names and payloads. Implement a configurable retry/backoff, circuit-breaker with observable metrics, and map Experian errors to domain-level outcomes. Ensure timeouts and fallbacks are covered by integration tests and simulated Experian responses.
