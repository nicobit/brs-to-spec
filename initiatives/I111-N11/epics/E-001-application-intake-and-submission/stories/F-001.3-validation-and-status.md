## User Story

As an Applicant, I want inline validation and the ability to retrieve my application status via ARN so that I can correct errors and check progress without registering.

---

## Business Context

Validation improves data quality and reduces manual review; ARN-based retrieval provides a low-friction status-check mechanism for applicants.

## Implementation Guidance

- **API:** GET /api/v1/applications/{arn}/status
- **Validation:** Field-level inline validation on client + server side

---

## Acceptance Criteria

### AC-001 — Inline validation `[unit]`

```gherkin
Scenario: Inline validation prevents submission with missing fields
  Given the applicant omits a required field
  When they attempt to submit
  Then the UI shows inline errors and blocks submission
```

### AC-002 — ARN status retrieval `[api]`

```gherkin
Scenario: Retrieve status by ARN
  Given a valid ARN and DOB
  When the applicant requests status
  Then the system returns the current status for that ARN
```
