# F-004.2 — KYC Identity Verification

| Field | Value |
|---|---|
| Layers | Integration, Backend |
| Story ID | F-004.2 |

## Business Context

Identity verification ensures the applicant is who they claim to be before offers are produced.

## User Story

As a Lender, I want the applicant's identity verified via HMRC so that downstream offers meet regulatory KYC requirements.

## Implementation Guidance

- Call HMRC identity verification API with required encrypted PII; use retry and fallback to manual verification when HMRC unavailable.

## Acceptance Criteria (Gherkin)

```gherkin
@integration @happy
Scenario: KYC verification succeeds
  Given an application with valid PII
  When HMRC identity verification returns a positive match
  Then the application is marked KYC_CLEAR and proceeds

@integration @negative
Scenario: KYC verification unavailable
  Given an application submission
  When HMRC verification is unavailable or returns inconclusive
  Then the application is routed to REFER_TO_UNDERWRITER and an audit entry records the reason
```

## Test Expectations

- Integration tests using HMRC sandbox and error simulations.

## Dependencies

- HMRC identity API credentials and sandbox.
