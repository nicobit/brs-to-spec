# F-005.1 — Offer Document Generation

| Field | Value |
|---|---|
| Layers | Backend, Integration |
| Story ID | F-005.1 |

## Business Context

Automatically generate a loan offer document populated with terms and acceptance instructions once approval and AML/KYC clearance are satisfied.

## User Story

As a System, I want to generate a signed offer document so that applicants can review terms and accept digitally.

## Implementation Guidance

- Use a templating engine to render offer documents with canonical fields; include ARN, loan terms, fee schedules, and signature workflow links.

## Acceptance Criteria (Gherkin)

```gherkin
@integration @happy
Scenario: Offer generated after approval and KYC/AML clear
  Given an approved application with AML/KYC clear
  When the offer generator runs
  Then a populated offer document is produced and stored and an applicant-facing link is available

@integration @negative
Scenario: Offer generation input missing
  Given missing required fields for offer generation
  When the generator runs
  Then generation fails with a validation error and an operational alert is raised
```

## Test Expectations

- Unit tests for templating logic, integration tests for document generation and storage, and e2e tests validating the applicant link and content.

## Implementation Guidance (additional)

- Reference the implementation contract for document field canonicalization and legal phrasing; ensure templating is locale-aware and includes encryption-at-rest when stored.
