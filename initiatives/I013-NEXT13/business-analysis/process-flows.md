# Process Flows

## Overview

This document contains high-level process flows for the initiative.

## Sample Flow: Application Submission

- Actors: Applicant, System, AI Scoring Service
- References: UC-001, UC-002, UC-003, UC-004

1. Applicant submits application (UC-001).
2. System validates and assigns ARN (UC-002).
3. System sends confirmation (UC-003) and triggers AI scoring (UC-004).
