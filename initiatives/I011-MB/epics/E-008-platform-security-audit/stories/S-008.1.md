# S-008.1 — Data residency & encryption

| Story ID | S-008.1 |
|---|---|
| Layers | Infrastructure |

Ensure storage and compute are provisioned in UK regions and enforce AES-256 encryption at rest.

| Story Type | Feature |

## User Story

As a security officer, I want all PII stored in UK regions with AES-256 encryption so that regulatory requirements are met.

## Implementation Guidance

Use platform KMS and storage account policies; document region constraints.

## Test Expectations

- Infrastructure compliance checks
- Configuration tests for encryption

```gherkin
Scenario: Storage is encrypted and UK region
	Given a storage account is provisioned
	When configuration is applied
	Then it is in UK region and encryption is AES-256
```
