# S-008.4 — Security monitoring & incident response

| Story ID | S-008.4 |
|---|---|
| Layers | Frontend / Integration / Infrastructure |

Integrate security monitoring, configure SIEM alerts, and define incident response runbooks.

| Story Type | Feature |

## User Story

As a security team member, I want SIEM integration and runbooks so that incidents are monitored and responded to.

## Implementation Guidance

Integrate logs with SIEM; define alerting and runbooks for incidents.

## Test Expectations

- Integration test with SIEM stub
- Runbook simulation

```gherkin
Scenario: SIEM receives security logs
	Given security logs are emitted
	When SIEM ingests logs
	Then alerts are generated according to rules
```
