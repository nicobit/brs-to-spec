# S-007.3 — Feature flags & admin controls

| Story ID | S-007.3 |
|---|---|
| Layers | Backend API / Frontend |

Provide feature flagging API and admin UI to toggle features safely.

| Story Type | Feature |

## User Story

As a product manager, I want to toggle features via flags so that we can perform safe rollouts.

## Implementation Guidance

Use centralized flag service; expose admin endpoints in the contract.

## Test Expectations

- Unit tests for flag evaluation
- Integration tests for admin UI

```gherkin
Scenario: Toggle feature flag on
	Given a feature flag is off
	When admin toggles it on
	Then the feature is enabled for users according to rollout rules
```
