# S-007.2 — Admin dashboards & alerts

| Story ID | S-007.2 |
|---|---|
| Layers | Frontend / Infrastructure |

Build admin dashboards and configure alerting rules with runbooks.

| Story Type | Feature |

## User Story

As an SRE, I want dashboards and alerts so that I can detect and respond to incidents.

## Implementation Guidance

Dashboards should read from MetricsStore and Alerts must integrate with Notifications.

## Test Expectations

- Dashboard integration tests
- Alerting threshold tests

```gherkin
Scenario: Alert triggers on high error rate
	Given error rate exceeds threshold
	When monitoring evaluates metrics
	Then an alert is raised and notification sent
```
