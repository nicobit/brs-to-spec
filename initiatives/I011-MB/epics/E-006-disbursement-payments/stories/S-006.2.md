# S-006.2 — Servicing UI changes

| Story ID | S-006.2 |
|---|---|
| Layers | Frontend |

Add servicing views: schedules, payments, and amendment flows in customer portal.

| Story Type | Feature |

## User Story

As a customer, I want to view my payment schedule so that I can understand upcoming payments and make amendments.

## Implementation Guidance

UI binds to `/api/v1/servicing/schedules/{applicationArn}` as defined in the contract.

## Test Expectations

- Component tests for UI
- Integration tests for bindings

## Required Tests

- 1 component test
- 1 integration test

```gherkin
Scenario: Customer views schedules
	Given the customer has schedules
	When they open the servicing page
	Then schedules and due dates are visible
```
