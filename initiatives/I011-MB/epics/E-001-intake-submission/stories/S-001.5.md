# S-001.5 — Infrastructure: Provision intake service and storage

| Story ID | S-001.5 |
|---|---|
| Layers | Infrastructure |

| Story Type | generic |

## User Story

As an operator I want the intake service and its storage provisioned and deployable via CI/CD so we can run the service in environment and meet NFRs.

## Business Context

Correct provisioning is required for availability, security, and performance (NFR-001).

## Requirements Implemented

- FR-006
- NFR-001
- NFR-003

## Requirements Referenced

- NFR-002

## In Scope

- IaC for compute, storage, secrets, and pipeline; monitoring hooks for observability.

## Implementation Guidance

Use the team's standard IaC templates; include secrets in secure vault and set RBAC for deployments.

## Test Expectations

- Integration test for deployment pipeline (smoke deploy)

## Required Tests

- 1 deployment smoke test
