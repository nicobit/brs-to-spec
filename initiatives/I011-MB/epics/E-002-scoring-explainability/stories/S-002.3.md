## User Story

As the Experian Adapter developer, I want a resilient adapter for Experian CreditExpert so that scoring can obtain credit inputs with fallback behaviour.

## Business Context

Experian availability is critical to scoring quality; resilience (timeouts, retries, circuit breaker) ensures system stability and consistent decisioning when external services fail.

## Acceptance Criteria

AC Tags: [important] [automate]

```gherkin
@important @automate
Scenario: Experian success
	Given a valid request to Experian
	When the adapter calls the external API
	Then a mapped credit report is returned within 30s

@important @automate
Scenario: Experian transient failure retry
	Given Experian returns intermittent 5xx responses
	When the adapter retries within policy
	Then eventual success returns mapped response or circuit breaker opens after threshold

@important @automate
Scenario: Adapter fallback
	Given Experian is unavailable
	When adapter exhausts retries
	Then the adapter returns an explicit failure and scoring marks refer-to-underwriter

@important @automate
Scenario: Mapping edge-case handled
	Given Experian returns unexpected fields or missing values
	When the adapter maps the response
	Then the adapter normalizes fields and returns a clearly defined mapping or an explicit validation error
```
