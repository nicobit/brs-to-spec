## User Story

As the Scoring Service, I want to process `application.submitted` events and compute a risk score and recommendation so that each submission receives an auditable score and routing decision.

## Business Context

Scoring is required to automate decisioning and to provide evidence for regulatory audit. Accurate scores with explainability traces reduce manual underwriter load and enable consistent decisioning.

## In Scope

- Consume `application.submitted` events
- Run scoring model, compute `score_value` and `recommendation`
- Persist `SCORE` record and emit `application.scored` with explainability reference

## Implementation Guidance

- **Entity:** SCORE (see implementation-contract.md)
- **API / Event:** consumes `application.submitted` event; emits `application.scored`
- **Status:** idempotent processing using submission id as key
- **Rules:** Apply BR-010 / BR-011 thresholds for recommendation

## Acceptance Criteria

AC Tags: [critical] [automate]

```gherkin
@critical @automate
Scenario: Happy path - scoring computes score and persists explainability
	Given an `application.submitted` event with valid application_arn and inputs
	When the scoring processor runs
	Then a `SCORE` record is persisted with `score_value` between 0 and 1000 and a `recommendation` in {AUTO_APPROVE, REFER_TO_UNDERWRITER, AUTO_DECLINE}
	And an `application.scored` event is emitted with `explainability_ref`

@important @automate
Scenario: Experian unavailable - fallback to referral
	Given Experian calls fail with timeouts
	When the scoring model requires credit inputs
	Then the recommendation is `REFER_TO_UNDERWRITER` and an audit event records the fallback

@standard @automate-later
Scenario: Idempotent reprocessing
	Given the same `application.submitted` event is delivered twice
	When the processor handles the duplicate
	Then the second processing does not create duplicate `SCORE` records and outcome is idempotent

@important @automate
Scenario: Threshold-based auto-approve
	Given an application with score_value >= 800 and loan_amount <= 10000
	When scoring completes
	Then the `recommendation` is `AUTO_APPROVE`
```
