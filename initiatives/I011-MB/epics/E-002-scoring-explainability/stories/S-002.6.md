## User Story

As an underwriter, I want the UI to display score and explainability payload for an application so that I can quickly review automated decisions.

## Business Context

Surface-level UI components reduce time-to-decision and give context to automated recommendations; explainability payload should be presented in human-friendly form.

## Acceptance Criteria

AC Tags: [standard] [manual]

```gherkin
@standard @manual
Scenario: Render score and explainability
	Given a score response with explainability_payload
	When the UI page loads
	Then the score and a summarized explainability view render correctly
  
@standard @automate
Scenario: Handle missing explainability gracefully
	Given a score without explainability_payload
	When the UI loads
	Then the UI shows score and a placeholder indicating explainability is unavailable

@important @automate
Scenario: Render long explainability payload in summarized form
	Given a large explainability_payload
	When the UI renders it
	Then the UI presents a summarized view with an option to expand raw JSON

@important @automate
Scenario: Authorization hides sensitive fields
	Given a user without elevated permissions
	When viewing explainability payload
	Then sensitive fields are redacted and only summary is shown
```
