## User Story

As an auditor or underwriter, I want to retrieve score and explainability payload via `GET /api/v1/scores/{id}` so that I can review the scoring rationale and results.

## Business Context

Providing a deterministic API to fetch `score` and `explainability_payload` is critical for audit, QA, and UI display. The API must honor access controls and return explainability data linked to the score.

## Acceptance Criteria

AC Tags: [critical] [automate]

```gherkin
@critical @automate
Scenario: Retrieve existing score and explainability
	Given a persisted SCORE with explainability_ref
	When GET /api/v1/scores/{id} is called with valid id
	Then the API returns 200 and a JSON body containing id, application_arn, score_value, recommendation and explainability_payload

@standard @automate-later
Scenario: Score not found
	Given no SCORE exists for id
	When GET is called
	Then the API returns 404

@important @automate
Scenario: Authorization enforced
	Given a caller without necessary permissions
	When GET is called for a protected record
	Then the API returns 403

@important @automate
Scenario: Response schema includes explainability payload and observability fields
	Given a persisted SCORE with explainability_ref
	When GET /api/v1/scores/{id} is called
	Then the response contains `explainability_payload` and observability metadata like `trace_id` and `event_timestamp`
```
