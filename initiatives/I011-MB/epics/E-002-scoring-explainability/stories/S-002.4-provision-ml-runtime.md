## User Story

As Platform, I want to provision an ML runtime (AKS or equivalent) so that the scoring service can run model inference with required performance.

## Business Context

Provisioning appropriate compute with GPU-enabled nodes and compliant storage ensures scoring runs within latency targets and explainability traces are persisted securely.
