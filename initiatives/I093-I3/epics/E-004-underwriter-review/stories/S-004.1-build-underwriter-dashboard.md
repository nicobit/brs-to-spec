## User Story

As an underwriter, I want a dashboard showing referred applications and key metadata so I can review and action them efficiently.

## Business Context

INVEST: Valuable — underwriters must triage referred applications to meet regulatory SLAs and reduce manual backlog.

## Gherkin Acceptance Criteria

```gherkin
Scenario: Underwriter views queue
	Given there are referred applications in the queue
	When the underwriter opens the dashboard
	Then they see a sortable list of referred applications with score, reason, and link to details

Scenario: Underwriter filters by priority
	Given the dashboard has multiple items
	When the underwriter filters by priority High
	Then only high-priority referred applications are shown
```
