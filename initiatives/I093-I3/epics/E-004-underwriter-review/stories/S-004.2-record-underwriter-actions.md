## User Story

As an underwriter, I want my decisions recorded immutably so audit trails can be reconstructed.

## Business Context

INVEST: Valuable — auditability is a regulatory requirement and supports dispute resolution.

## Gherkin Acceptance Criteria

```gherkin
Scenario: Record decision
	Given an underwriter takes action Approve on an application
	When the system records the action
	Then an immutable audit entry is persisted with timestamp and user id

Scenario: Action includes reason
	Given an underwriter records a decision
	When they submit the decision with reason
	Then the reason is stored and retrievable from the audit log
```

Persist decisions to the audit-log service as append-only events.
