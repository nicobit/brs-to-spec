# S-002.2 — Integrate Experian retrieval

| Field | Value |
|---|---|
| Layers | Integration |

Requirement Traceability:
- FR-009: Experian integration for credit report

## Business Context
Credit bureau data enriches scoring and reduces risk in decisions.

## User Story
As the system, I want to retrieve credit reports from Experian so that the scoring model has enriched inputs.

## Implementation Guidance
Use a resilient adapter with retry/backoff and circuit-breaker patterns.

## Test Expectations
- Contract tests and integration tests with experiment sandbox

## Acceptance Criteria (Gherkin)

```gherkin
Scenario: Successful Experian retrieval
  Given a scoring job with applicant data
  When the Experian adapter is called
  Then a credit report is returned within 30s

Scenario: Experian unavailable
  Given Experian returns an error
  When the system handles the failure
  Then the scoring job is routed to underwriter with a note
```
