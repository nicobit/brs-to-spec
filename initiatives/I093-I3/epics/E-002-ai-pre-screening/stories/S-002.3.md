# S-002.3 — Attach explainability metadata

| Field | Value |
|---|---|
| Layers | Backend |

Requirement Traceability:
- FR-007: AI scoring model output

## Business Context
Explainability supports auditability and underwriter review.

## User Story
As an underwriter, I want explainability metadata attached to scores so that I can interpret model outputs.

## Implementation Guidance
Include SHAP-like feature attributions and minimal explanation payload per score.

## Test Expectations
- Example-driven tests validating explanation schema

## Acceptance Criteria (Gherkin)

```gherkin
Scenario: Explainability attached
  Given a scoring result
  When the result is stored
  Then explainability metadata is included in the result payload

Scenario: Explainability absent
  Given the model cannot produce explanations
  When the result is returned
  Then a reason is attached indicating limited explainability
```
