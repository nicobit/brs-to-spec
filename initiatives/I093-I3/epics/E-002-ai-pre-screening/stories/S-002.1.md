# S-002.1 — Implement scoring API

| Field | Value |
|---|---|
| Layers | Backend, Integration |

Requirement Traceability:
- FR-006: AI pre-screening trigger
- FR-007: AI scoring model output

## Business Context
Scoring enables rapid routing of applications and reduces manual effort for underwriters.

## User Story
As the system, I want to accept scoring jobs and return job ids so that scoring can be performed asynchronously.

## Implementation Guidance
Follow the implementation contract; ensure idempotency and job tracking.

## Test Expectations
- Integration tests for job lifecycle

## Acceptance Criteria (Gherkin)

```gherkin
Scenario: Submit scoring job
  Given a valid application payload
  When the system enqueues a scoring job
  Then it returns 202 Accepted and a job id

Scenario: Job processing failure
  Given the scoring backend fails
  When the job is processed
  Then the job is marked failed and monitoring alerts are raised
```
