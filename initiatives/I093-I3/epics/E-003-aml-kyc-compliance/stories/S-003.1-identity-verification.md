## User Story

As an Applicant, I want to upload identity documents and have them automatically verified, so that onboarding proceeds faster when verification succeeds.

---

## Business Context

Identity verification reduces manual effort and fraud risk and is a regulatory prerequisite for downstream AML screening and offer generation.

## Implementation Guidance

- **Entity:** Applicant, VerificationResult
- **API:** POST `/api/applications/{applicationId}/verify`
- **Events:** ApplicantVerified
- **Rules:** Verification must produce a confidence score and a status (passed/failed/partial)

---

## Acceptance Criteria

### AC-001 — Successful verification `[integration]`

```gherkin
Scenario: Document upload and vendor verification success
  Given an applicant has uploaded valid identity documents
  When the system submits them to the verification vendor
  Then the vendor returns status "passed" and the application proceeds to screening
```

### AC-002 — Verification failure `[integration]`

```gherkin
Scenario: Vendor cannot verify identity
  Given an applicant uploaded poor-quality documents
  When the vendor returns status "failed"
  Then the application is flagged "needs_manual_review" and a reviewer task is created
```
