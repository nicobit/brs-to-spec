## User Story

As a Compliance Officer, I want a consolidated risk summary and reviewer task for flagged applicants, so I can triage and resolve potential compliance issues.

---

## Business Context

Consolidated risk summaries reduce time-to-resolution for high-risk cases and provide audit evidence for decisions.

## Implementation Guidance

- **Entity:** ScreeningResult, ReviewerTask
- **API:** GET `/api/applications/{applicationId}/risk-summary`
- **Events:** HighRiskApplicantDetected
- **Rules:** Create reviewer task when score >= threshold or sanction match present

---

## Acceptance Criteria

### AC-001 — Reviewer task created `[integration]`

```gherkin
Scenario: High risk applicant requires manual review
  Given an applicant with screening score >= threshold
  When screening completes
  Then a reviewer task is created with a consolidated risk summary
```

### AC-002 — Risk summary visible `[api]`

```gherkin
Scenario: Compliance officer views risk summary
  Given a reviewer task exists for an applicant
  When the officer requests the risk summary
  Then the API returns screening details, verification result, and recommended next steps
```
