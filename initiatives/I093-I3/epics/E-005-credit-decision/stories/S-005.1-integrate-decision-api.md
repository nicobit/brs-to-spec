## User Story

As a system, I want to call the credit decision API to receive a recommendation for an application.

## Business Context

INVEST: Valuable — automating decisions reduces manual work and speeds throughput.

## Gherkin Acceptance Criteria

```gherkin
Scenario: Request decision
  Given applicant data is available
  When the system requests a decision from the credit API
  Then a recommendation is returned with a score

Scenario: Handle API error
  Given the credit API is unavailable
  When the system requests a decision
  Then an error is returned and the application is marked for manual review
```
