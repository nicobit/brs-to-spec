## User Story

As a system, I want to fallback to manual review when the decision API fails so no applications are lost.

## Business Context

INVEST: Valuable — fault tolerance prevents loss of business flow during outages.

## Gherkin Acceptance Criteria

```gherkin
Scenario: Fallback to manual review
  Given the credit API returns an error
  When the system cannot obtain a recommendation
  Then the application is enqueued for manual review

Scenario: Retry policy
  Given transient API failures
  When the system retries a request
  Then it retries up to 3 times before enqueuing for manual review
```

Implement retry policy and enqueue to manual-review queue defined by infra team; reference implementation contract events for enqueueing.
