## User Story

As a compliance officer, I want scheduled reports exported to CSV so I can submit regulatory filings.

## Business Context

INVEST: Valuable — automates compliance reporting.

## Gherkin Acceptance Criteria

```gherkin
Scenario: Generate scheduled report
  Given a scheduled job exists
  When the schedule triggers
  Then a report is generated and stored

Scenario: Export report
  Given a generated report
  When the officer requests export
  Then the report is downloadable as CSV
```

## Implementation Guidance

Implement scheduled jobs and storage of report artifacts.

## Test Expectations

- Integration tests for scheduled job execution
