## User Story

As an analyst, I want dashboards showing operational metrics so I can monitor system health.

## Business Context

INVEST: Valuable — helps detect regressions and performance issues early.

## Gherkin Acceptance Criteria

```gherkin
Scenario: View dashboard
  Given metrics are available
  When the analyst opens the dashboard
  Then key KPIs are displayed

Scenario: Drill-down
  Given a KPI is selected
  When the analyst drills down
  Then detailed data is shown for the selected period
```

## Implementation Guidance

Consume metrics API endpoints and render using charts.

## Test Expectations

- UI tests for dashboard rendering
