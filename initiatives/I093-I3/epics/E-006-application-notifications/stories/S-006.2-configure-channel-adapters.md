## User Story

As an operator, I want to configure channel adapters so notifications can be delivered via email/SMS.

## Business Context

INVEST: Valuable — flexible adapters let us switch providers without code changes.

## Gherkin Acceptance Criteria

```gherkin
Scenario: Configure email adapter
  Given operator configures email provider
  When a notification is sent
  Then the provider is used to deliver the message

Scenario: Fallback provider
  Given primary provider fails
  When sending notification
  Then fallback provider is used
```

## Implementation Guidance

Provide adapter interfaces and configuration via runtime config; ensure secure storage of credentials.

## Test Expectations

- Adapter integration tests
