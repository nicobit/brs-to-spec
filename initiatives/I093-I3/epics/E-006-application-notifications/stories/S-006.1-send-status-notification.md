## User Story

As a system, I want to send status notifications to customers when their application status changes.

## Business Context

INVEST: Valuable — customers expect timely status updates.

## Gherkin Acceptance Criteria

```gherkin
Scenario: Send notification on status change
  Given an application status changes to Approved
  When the notification service is triggered
  Then a notification is sent to the customer via configured channels

Scenario: Handle provider failure
  Given a channel provider returns an error
  When the notification is sent
  Then the failure is retried and logged
```

## Implementation Guidance

Use `/notifications/send` API to dispatch messages; integrate with provider adapters.

## Test Expectations

- Integration tests with mock providers
