# UC-008: E-sign Offer

## Description

Applicant accepts offer via e-signature (DocuSign).

## Primary Actor

Applicant

## Main Success Scenario

1. Applicant signs via DocuSign and system records signature proof.
2. System marks offer as `ACCEPTED` and begins cooling-off period.

## Postconditions

- Offer acceptance recorded with timestamp and signature reference.

## Source FRs

- FR-022, FR-023
