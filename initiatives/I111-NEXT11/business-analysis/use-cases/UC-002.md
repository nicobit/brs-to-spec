# UC-002: AI Pre-screening & Scoring

## Description

System performs AI scoring and produces risk score and recommendation.

## Primary Actor

System (AI service)

## Main Success Scenario

1. System receives application ARN and fetches required data.
2. AI model computes score (0–1000) and recommendation.
3. System stores score and recommendation in application record.

## Postconditions

- Application updated with `risk_score` and `ai_recommendation`.
