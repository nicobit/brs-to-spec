# UC-006: Disburse Funds

## Description

Trigger disbursement to core banking upon acceptance and cooling-off expiry.

## Primary Actor

System (Disbursement service)

## Main Success Scenario

1. System sends disbursement instruction to Temenos T24.
2. System awaits confirmation and updates application status to `DISBURSED`.

## Postconditions

- Disbursement recorded and applicant notified.

## Source FRs

- FR-024, FR-025, FR-026
