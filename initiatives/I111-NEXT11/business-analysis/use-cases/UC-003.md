# UC-003: AML/KYC Screening

## Description

Perform AML and KYC checks and mark application accordingly.

## Primary Actor

System (AML/KYC integrations)

## Main Success Scenario

1. System calls AML and KYC providers.
2. If AML/KYC pass, continue; else mark `COMPLIANCE_HOLD`.

## Postconditions

- Application status updated with AML/KYC result.

## Source FRs

- FR-012, FR-013, FR-014
