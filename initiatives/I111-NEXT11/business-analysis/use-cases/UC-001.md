# UC-001: Submit Application

## Description

Applicant submits a loan application with required fields.

## Primary Actor

Applicant

## Preconditions

- Applicant has access to the application portal.

## Main Success Scenario

1. Applicant fills application form and submits.
2. System validates required fields and returns inline errors if needed.
3. System assigns ARN and returns confirmation to applicant.
4. System triggers AI pre-screening (UC-002).

## Postconditions

- Application record created with ARN and initial status `SUBMITTED`.

## Source FRs

- FR-001, FR-002, FR-003
