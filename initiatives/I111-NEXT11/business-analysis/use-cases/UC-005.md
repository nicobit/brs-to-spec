# UC-005: Generate Offer

## Description

System generates a loan offer after approval.

## Primary Actor

System

## Main Success Scenario

1. System composes offer document with APR, monthly payments, term.
2. Offer is stored and presented to applicant.

## Postconditions

- Offer available via portal and email; valid for 14 days.

## Source FRs

- FR-020, FR-021
