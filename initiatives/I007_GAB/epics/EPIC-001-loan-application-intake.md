# EPIC-001 — Loan Application Intake

Summary:

- Build the public-facing application intake experience, including form validation, ARN assignment, and applicant communications.

Linked Requirements:

- FR-001, FR-002, FR-003, FR-004

Acceptance Criteria (minimal):

- Intake form submits valid applications and returns an ARN.
- Applicant receives confirmation email within 2 minutes.
