## User Story

As a Platform operator, I want a Scoring end-to-end POC that ingests a synthetic submission, runs model inference, stores explainability artifacts, and emits scoring results, so that we can validate the scoring pipeline and downstream integrations.

## Business Context

Verify scoring pipeline ingestion, inference, explainability persistence, and downstream event emission end-to-end using a synthetic application submission.
