# S-003.2 - Underwriter case API

| Field | Value |
|---|---|
| Story ID | S-003.2 |
| Title | Underwriter case API |
| Layers | backend / frontend |
| Story Type | feature |

## User Story

As a Product owner, I want an API to create and retrieve compliance cases so underwriters can review flagged applications.

## Business Context

Persist compliance cases and expose them to the underwriter dashboard including explainability artifacts.


## Linked Requirements

| ID | Requirement |
|---|---|
| FR-019 | Escalation after 4 business hours |

## Requirements Implemented

- FR-019

## In Scope

- Create and retrieve compliance cases via API; include references to explainability artifacts.

## Implementation Guidance

- Implement `POST /api/cases` to persist case metadata and references to explainability artifacts. Ensure immutability and audit trail for case actions.

## Acceptance Criteria

### AC-001 — Create and retrieve case `[api]` `[critical]` `[automate]`

```gherkin
Scenario: Compliance case created and retrievable via API
  Given a COMPLIANCE_HOLD result
  When the system creates a compliance case
  Then the case is retrievable via the case API including explainability references
```

### AC-002 — Missing explainability reference handled `[api]` `[important]` `[automate]`

```gherkin
Scenario: Case created without explainability reference
  Given a COMPLIANCE_HOLD without attached explainability
  When the system creates a case
  Then the case is created with an indicator that explainability is pending
```

### AC-003 — Immutable case records `[integration]` `[important]` `[automate]`

```gherkin
Scenario: Case actions are immutable
  Given an existing case
  When an update attempt is made that should be immutable
  Then the system rejects writes that violate immutability and records an audit entry
```

### AC-004 — Retrieval performance and pagination `[api]` `[standard]` `[automate]`

```gherkin
Scenario: Case list retrieval with pagination
  Given a set of cases
  When a client requests a paginated list
  Then the API returns a page of cases and includes pagination links
```
