# S-001.2 - Intake API: submit application

## Metadata

| Field | Value |
|---|---|
| Story ID | S-001.2 |
| Title | Intake API: submit application |
| Layers | backend |
| Story Type | backend-endpoint |

## User Story

As an applicant submitting an application, I want to POST my application so that the system creates an ARN and queues scoring.

## Business Context

This story implements the Intake POST endpoint with validation and persistence, enabling downstream decisioning.

## Linked Requirements

| Requirement | Title |
|---|---|
| FR-001 | Loan application submission |
| FR-002 | Inline validation before submission |
| FR-003 | Assign Application Reference Number (ARN) |

## Requirements Implemented

- FR-001, FR-002, FR-003

## Requirements Referenced

- NFR-004 (PII encryption)

## In Scope

- POST /api/intake/submit input validation, persistence, ARN generation, publish application.submitted event.

## Implementation Guidance

Follow `implementation-contract.md` for request schema and event payload. Persist application with UK-only storage configuration.

## Dependency Contracts

- Scoring pipeline consumer (mock)
- Audit store

## Acceptance Criteria

### [backend] [critical] [automate]
```gherkin
Scenario: Valid submission returns ARN
  Given a valid application payload
  When POST /api/intake/submit is called
  Then respond 201 with JSON containing arn
```

### [backend] [important] [automate]
```gherkin
Scenario: Invalid loan amount returns 400
  Given loan_amount = 500000 (above max)
  When POST /api/intake/submit is called
  Then respond 400 with validation error for loan_amount
```

### [integration] [standard] [automate]
```gherkin
Scenario: Event published after successful persist
  Given a successful persist
  When the handler completes
  Then an application.submitted event is published containing arn
```

### [integration] [edge] [automate]
```gherkin
Scenario: Missing required field returns 400
  Given a payload missing ni_number
  When POST /api/intake/submit is called
  Then respond 400 with validation error for ni_number
```
