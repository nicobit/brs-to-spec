## Business Context

Lightweight spike to validate frontend form submission wiring and infrastructure components (CI mocks, deployment hooks, observability) required for the POC.

## User Story

As an engineer responsible for the POC environment, I want the frontend form to reliably submit a loan application payload (applicant details, DOB, NI number, income, loan amount) to the intake API so that the system creates a persistent application record, returns a stable ARN, and emits the application.submitted event for downstream consumers. The story must preserve the intent of FR-001 (Loan application submission): validate required fields, persist the application, produce ARN, and surface any validation errors to the frontend.

Success criteria:

- A manual smoke submission from the POC frontend reaches the intake API and returns an ARN and persisted application record.
- CI pipeline includes mock providers and a verification job that asserts traces and mocks are wired, and that PII handling conforms to NFR-004.
