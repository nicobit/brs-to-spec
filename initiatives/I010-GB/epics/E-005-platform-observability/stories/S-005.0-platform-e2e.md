## User Story

As a Platform operator, I want a minimal end-to-end proof-of-concept that ingests synthetic events, appends them to the audit store, and surfaces a metric in a dashboard so that we can validate the observability and pipeline plumbing before implementing production-grade components.

## Business Context

The POC demonstrates that telemetry, audit append, and metrics pipelines work together end-to-end. It reduces risk by validating integration points and informs decisions about storage technology and retention.

## Implementation Guidance

- **Entity:** AuditEntry (see ../implementation-contract.md)
- **API:** POST /api/platform/audit (synthetic workload)
- **Status:** POC — non-production backing store allowed
- **Events:** audit.event.appended produced on successful append
- **Rules:** Ensure synthetic data respects residency constraints for the POC environment

## Acceptance Criteria

### AC-001 — End-to-end append `[e2e]` `[critical]` `[automate]`

```gherkin
Scenario: Append and observe metric
	Given the POC platform stack is deployed
	When synthetic events are POSTed to /api/platform/audit
	Then the API responds 201 and a metric reflecting the appended count is visible in the dashboard
```

### AC-002 — Append API contract `[api]` `[important]` `[automate]`

```gherkin
Scenario: Append a valid audit event
	Given the Platform API is available
	When a client POSTs a valid audit event payload to /api/platform/audit
	Then the API responds with 201 and a persisted audit entry id
```

### AC-003 — Reject invalid payloads `[api]` `[important]` `[automate]`

```gherkin
Scenario: Reject invalid audit payload
	Given the Platform API is available
	When a client POSTs an invalid audit payload
	Then the API responds with 422 and a validation error
```

### AC-004 — Metrics ingestion `[integration]` `[standard]` `[automate]`

```gherkin
Scenario: Metrics pipeline ingests sample events
	Given synthetic events are appended
	When the metrics pipeline runs
	Then the dashboard displays a non-zero count for ingested events
```
