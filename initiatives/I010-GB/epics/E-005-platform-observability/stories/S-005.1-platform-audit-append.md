## User Story

As the Platform API, I want to append audit events to an immutable audit store so that downstream systems (analytics, compliance) can consume tamper-evident event history.

## Business Context

Appending audit events provides a reliable, auditable trail of system activity required for compliance, analysis, and troubleshooting. It ensures business processes are traceable and supports regulatory requirements around data residency and integrity.

## Acceptance Criteria

### AC-001 — Append valid audit event `[api]` `[critical]` `[automate]`

```gherkin
Scenario: Append a valid audit event
  Given the Platform API is available
  When a client POSTs a valid audit event payload to /api/platform/audit
```

