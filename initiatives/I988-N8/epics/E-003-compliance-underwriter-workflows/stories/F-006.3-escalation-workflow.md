## User Story

As an Underwriter Lead, I want escalation paths for tasks that require specialist review so that high-risk cases are routed correctly.

---

## Business Context

Certain screening outcomes or SLA breaches demand specialist input; automated routing to escalation queues reduces mean time to resolution and improves compliance.

## Implementation Guidance

- Escalation creates a new task with origin reference and escalated flag; notification sent to specialist group.

---

## Acceptance Criteria

### AC-001 — Escalation creates specialist task `[integration]`
```gherkin
Scenario: Create specialist escalation task
  Given a task requires specialist input
  When escalation is triggered
  Then a new task is created with escalated=true and notification sent to specialist group
```

### AC-002 — Escalation rejection `[unit]`
```gherkin
Scenario: Escalation fails when no specialist group configured
  Given a task requires specialist input but no specialist group exists
  When escalation is attempted
  Then the API returns 422 and an `audit.event` records the failure reason
```
