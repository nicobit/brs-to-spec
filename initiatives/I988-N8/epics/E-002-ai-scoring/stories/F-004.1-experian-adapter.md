## User Story

As an **integration adapter**, I provide Experian credit lookup responses to the scoring service so the scorer can include credit information in the score.

---

## Business Context

Credit lookups improve scoring accuracy and reduce false positives. The adapter isolates Experian-specific mapping and retries so the scoring service remains clean.

---

## Linked Requirements

- REQ-005, REQ-018, FR-010, FR-011

---

## Implementation Guidance

- Implement a resilient adapter with retry/backoff and mapping layer. Provide contract tests and a mock service for local development.

## Acceptance Criteria

### AC-001 — Adapter returns data `[integration]`

```gherkin
Scenario: Experian returns credit payload
  Given Experian test credentials
  When the adapter requests credit data for a given national id
  Then it returns the credit payload mapped to the internal schema
```

### AC-002 — Adapter handles transient failures `[integration]`

```gherkin
Scenario: Experian transient error retries
  Given Experian API returns 503
  When adapter retries with backoff
  Then it either returns cached data or fails gracefully with audit log
```
