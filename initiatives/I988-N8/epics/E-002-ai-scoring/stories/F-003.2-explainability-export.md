## User Story

As a **compliance engineer**, I need explainability metadata stored with each score so regulators can inspect decisions.

---

## Business Context

Regulators and auditors require provenance for automated decisions; storing explainability metadata ensures traceability and supports appeals or investigations.

---

## Linked Requirements

- REQ-014, REQ-017, FR-009

---

## Implementation Guidance

- Persist explainability in a compacted JSON column and index by model_version; reference `implementation-contract.md` for the event schema.
