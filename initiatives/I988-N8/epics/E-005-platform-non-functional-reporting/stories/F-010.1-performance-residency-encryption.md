## Acceptance Criteria

### AC-001 — Residency enforcement `[integration]`
```gherkin
Scenario: Data stored only in UK region
  Given platform configured for UK-only regions
  When personal data is written
  Then storage service stores data in UK-backed storage and logs region
```

### AC-002 — Key vault usage `[integration]`
```gherkin
Scenario: Secrets stored in Key Vault
  Given a service needs an encryption key
  When creating the key
  Then it is stored in Key Vault and not in plaintext config
```
