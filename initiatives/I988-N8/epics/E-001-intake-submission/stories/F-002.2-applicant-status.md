## User Story

As an **applicant**, I want to view the current status of my application using my ARN so that I can know whether further information or actions are required.

---

## Business Context

Status visibility reduces support contacts and helps applicants complete missing steps quickly.

---

## Linked Requirements

- REQ-016

---

## Implementation Guidance

- Provide a read endpoint `GET /api/v1/applications/{arn}/status` which returns canonical status and timeline. Ensure authorization for private data.

---

## Acceptance Criteria

### AC-001 — Status retrieval `[api][integration]`

```gherkin
Scenario: Applicant retrieves status with ARN
  Given an existing application with arn
  When the applicant GETs /api/v1/applications/{arn}/status
  Then the API returns 200 with current status and last_updated
```

### AC-002 — Unauthorized access `[unit]`

```gherkin
Scenario: Unauthorized request is rejected
  Given a request missing valid auth token
  When the API endpoint is called
  Then the API returns 401 Unauthorized
```
