## User Story

As an **applicant**, I want to complete an online application form and submit my details so that I can receive an ARN and track my application status.

---

## Business Context

Submitting applications online increases conversion and reduces manual intake workload for operations.

## Acceptance Criteria

### AC-001 — Happy path `[api][integration]`

```gherkin
Scenario: Applicant submits valid form and receives ARN
  Given the applicant provides valid applicant_name and applicant_email
  When they POST to /api/v1/applications
  Then the API returns 201 with an ARN and created_at
```

### AC-002 — Validation error `[unit]`

```gherkin
Scenario: Missing email returns validation error
  Given the payload is missing applicant_email
  When validation runs
  Then the validator returns a clear error indicating missing applicant_email
```
