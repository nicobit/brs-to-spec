## Preconditions

- Application form is available and required fields are shown
- Applicant has internet access and required identity data

## Main Success Scenario

| Step | Actor | Action |
|---|---|---|
| 1 | Applicant | Fills required fields and submits application form |
| 2 | System | Validates inputs and returns validation errors if present |
| 3 | System | Assigns ARN and persists application |
| 4 | System | Returns confirmation to applicant and sends email with ARN |

## Alternative Flows

### A1: Invalid input

| Step | Actor | Action |
|---|---|---|
| A1.1 | System | Reject submission with field-level errors |

## Exception Paths

### E1: Email delivery failure

| Step | Actor | Action |
|---|---|---|
| E1.1 | System | Retry email send twice, record failure and surface to ops if still failing |

## Postconditions

**Success:** ARN created and application stored; applicant notified.

**Failure:** Submission rejected with validation errors.
