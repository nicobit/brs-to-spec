# Software Modules

This document identifies the top-level software modules for delivery.

- `portal-app` — Applicant Portal and static assets
- `api-gateway` — Azure API Management and gateway adapters
- `application-service` — Core application APIs (eligibility, submission)
- `integration-adapters` — Adapters for Experian, DocuSign, T24, payments
- `ai-scoring` — AI scoring model and inference service
- `data-platform` — Audit store, persistence, event store, analytics

Notes: Modules map to team boundaries and CI/CD pipelines.
