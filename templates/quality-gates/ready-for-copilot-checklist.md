# Ready for Copilot Checklist

Before asking Copilot to implement, verify:

- [ ] OpenSpec proposal is approved.
- [ ] OpenSpec design is approved.
- [ ] Task is small enough for one coding session.
- [ ] Task has clear requirements coverage.
- [ ] Task has user stories / acceptance criteria coverage.
- [ ] Task has expected tests.
- [ ] Task has Definition of Done.
- [ ] Security / authorization expectations are clear.
- [ ] Database impact is clear or not applicable.
- [ ] Integration impact is clear or not applicable.
- [ ] No critical open question blocks the task.
- [ ] Copilot is not asked to implement directly from the BRS.
