# Handoff Ready Checklist

## Required upstream artifacts

- [ ] BRS extracted or summarized.
- [ ] Architecture draft extracted if available.
- [ ] Requirements extracted.
- [ ] BRS / requirements / architecture alignment completed or explicitly skipped.
- [ ] Delivery structure created.
- [ ] User stories created.
- [ ] Gaps and questions reviewed.
- [ ] Technical spec created.

## Optional artifacts

- [ ] Enablement scope completed if infrastructure / CI-CD / operations are affected.
- [ ] Architecture-contract artifact decision completed if engineering ambiguity is high.
- [ ] Required ADRs/API/data/event/domain/security/NFR artifacts completed.

## Handoff package

- [ ] `handoff/spec-driven-handoff.md` exists.
- [ ] Recommended downstream mode is selected.
- [ ] Blocking issues are clearly marked.
- [ ] Open questions have owners.
- [ ] Risks are visible.
- [ ] Acceptance/validation expectations are included.

## Source of truth

- [ ] If downstream framework is used, it is clear where execution ownership moves.
- [ ] If standalone mode is used, this repository remains the source of truth.
