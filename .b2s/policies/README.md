# Policy Library

Policy files are governance inputs for artifact generation.

Use a policy file when an action needs explicit rules about:

- wording and structure
- architecture and technology constraints
- security and compliance expectations
- coding and implementation boundary expectations
- testing and handoff expectations

Policy files are not prompts and not templates:

- prompts explain how to think and what to produce
- templates define the output shape
- policies define rules the output must respect

Policy files should stay short, operational, and reusable across actions.
