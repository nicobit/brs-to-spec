# Roles and Responsibilities

| Role | Owns | Approves |
|---|---|---|
| Business PO | Business intent, process, business rules | User stories, acceptance criteria |
| BA / Analyst | Requirement extraction and clarification | Requirements completeness |
| Architect / Tech Lead | Technical spec and architecture constraints | Design and implementation task split |
| QA Lead | Test strategy, test plan, acceptance testability | QA readiness |
| Security / Risk | Authorization, data protection, sensitive operations | Security readiness |
| Developer | Implementation and tests | Code quality before PR |
| Copilot | Assisted implementation only | Nothing; Copilot does not approve |
| Human Reviewer | PR review | Merge readiness |

## Key principle

Copilot is an implementation assistant, not a decision maker.

Human roles own approvals.
