# Copilot Studio Agent Design

Use Copilot Studio when you need a more controlled workflow.

## Topics

1. Start BRS intake
2. Select BRS and architecture document
3. Create BRS summary
4. Extract requirements
5. Identify gaps/questions
6. Create delivery slicing
7. Create approval checklist
8. Notify IT / save output

## Knowledge sources

- SharePoint BRS Intake site
- BRS templates
- approved examples
- governance guidance

## Actions

Phase 1:
- manual SharePoint output

Phase 2:
- create SharePoint pages/lists automatically
- notify IT

Phase 3:
- create repository branch
- create OpenSpec change
- open PR/MR

## Rule

Do not write directly to `main`.
