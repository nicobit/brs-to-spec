## Why This Framework Exists

<div class="signal-row">
  <div class="signal-card">
    <strong>Controlled path</strong>
    <span>BRS documents carry ambiguity, assumptions, and hidden delivery risk. This framework makes them explicit before engineering begins.</span>
  </div>
  <div class="signal-card">
    <strong>One artifact at a time</strong>
    <span>Each stage produces one traceable, decision-oriented artifact. Copilot works from approved output, not raw requirements.</span>
  </div>
  <div class="signal-card">
    <strong>Proportional process</strong>
    <span>Fast Path for narrow changes. Enterprise + Modular for multi-team work. Use the lightest safe path.</span>
  </div>
</div>
