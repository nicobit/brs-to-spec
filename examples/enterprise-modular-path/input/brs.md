# BRS — Example

## Objective

Improve client onboarding by allowing authorized users to create onboarding requests, compliance users to approve/reject them, and all status changes to be audited.

## Requirements

| Requirement ID | Requirement |
|---|---|
| REQ-001 | Authorized users can create onboarding requests. |
| REQ-002 | Compliance users can approve or reject requests. |
| REQ-003 | All status changes must be auditable. |
