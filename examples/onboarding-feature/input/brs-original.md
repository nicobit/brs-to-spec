## Original Structure

The business wants Relationship Managers to create onboarding requests for new clients.

An onboarding request must include:
- client name
- client type
- booking location
- risk category

Only users with the Relationship Manager role can create requests.

Compliance users can approve or reject requests.

Every status change must be auditable.

The system must show validation errors when mandatory fields are missing.
