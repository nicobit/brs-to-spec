
# S-001.3 — Status lookup

| Field | Value |
|---|---|
| Layers | Infrastructure, Integration |

Requirement Traceability:
- FR-005: Application status retrieval by ARN
- NFR-001: Page load performance
- REQ-001

## Business Context
Applicants need to retrieve status without accounts; performance impacts user satisfaction and support load.

## User Story

As an applicant, I want to check my application status by ARN so that I can know progress without creating an account.

## Description
Implement status lookup by ARN; ensure status endpoints meet performance SLAs and return privacy-preserving responses.


## Implementation Guidance

Implement efficient status cache and paging for public endpoints; ensure privacy-preserving responses.

## Test Expectations

- Load tests for status endpoint to confirm NFR-001

## Acceptance Criteria (Gherkin)

```gherkin
Scenario: Happy path - status lookup
	Given an applicant has ARN and DOB
	When they query the status endpoint
	Then the system returns the current status within performance SLA

Scenario: Status lookup - invalid ARN
	Given an applicant provides an invalid ARN
	When they query the status endpoint
	Then the system returns a 404 or generic not-found response without leaking PII
```
